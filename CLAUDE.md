## Git

- Faça commit e push ao concluir cada tarefa lógica, sem acumular várias mudanças num único commit.
- Use a convenção do GitHub (Conventional Commits): `tipo(escopo opcional): descrição`, com tipos como `feat`, `fix`, `docs`, `refactor`, `test`, `chore`.
- Mensagem no imperativo, em português, com a primeira linha de até 72 caracteres; use o corpo do commit para explicar o porquê, quando necessário.
- Faça o push para o remoto logo após o commit.
